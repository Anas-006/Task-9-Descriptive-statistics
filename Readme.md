Task 9 – Descriptive Statistics Primer

Project Overview

This project focuses on understanding and interpreting descriptive statistics using the Iris dataset. The analysis calculates mean, median, mode, standard deviation, and percentiles for four key numeric columns.

Dataset

Dataset: Iris Dataset

Numeric columns analyzed:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Tools Used

- Python
- Pandas
- Excel

Analysis Performed

The following descriptive statistics were calculated:

- Mean
- Median
- Mode
- Standard Deviation
- 25th Percentile
- 50th Percentile
- 75th Percentile

Mean and median were compared to understand possible skew, while standard deviation and percentiles were used to understand the spread and variability of the data.

Key Findings

Sepal Length has a mean of 5.84 and a median of 5.80, showing that the two measures are close and suggesting relatively little skew.

Sepal Width has a mean of 3.06 and a median of 3.00, indicating a fairly balanced distribution.

Petal Length has a standard deviation of 1.77 compared with a mean of 3.76, showing greater variation in the observations.

Petal Width has a standard deviation of 0.76, while the middle 50% of observations falls between 0.30 and 1.80, indicating noticeable variation.

Deliverables

- Python descriptive statistics script
- Excel summary statistics workbook
- Analysis and interpretation
- Rollback evidence

Outcome

The project demonstrates how descriptive statistics can be used to understand the center, spread, and distribution of numeric data and provides practical intuition for choosing appropriate statistical measures.
